# Contributing

This repository is limited to public discovery metadata and related documentation for Process Street's hosted MCP Server.

Before proposing a change:

1. Confirm the behavior against the official [MCP Server guide](https://www.process.st/help/docs/mcp-server/).
2. Keep implementation details, credentials, customer information, and vulnerability reports out of issues and pull requests.
3. Run `./scripts/validate.sh`.
4. Use a new semantic version for any metadata revision intended for the Official MCP Registry. Published Registry versions are immutable.

For product support or security concerns, follow the routes in [`SUPPORT.md`](SUPPORT.md) and [`SECURITY.md`](SECURITY.md).
